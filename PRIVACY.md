# Window Seat · 舷窗 Privacy Policy / 隐私政策

Effective date: October 24, 2026 / 生效日期：2026 年 10 月 24 日

Window Seat does not collect personal data. It has no account system, analytics, advertising, tracking, or in-app purchases. Game progress and preferences are stored on your device. Nearby multiplayer shares only the game session data needed to play with devices you connect to over Bluetooth or local Wi-Fi; this data is not sent to the developer's servers. You can remove locally stored data by deleting the app. Apple may process information about your App Store purchase under [Apple's Privacy Policy](https://www.apple.com/legal/privacy/), independently of Window Seat. The Android version is downloaded from GitHub and checks for updates: when “Check for updates automatically” is on (the default) and a network is available, it asks GitHub for new releases at most once every 24 hours, and you can also check manually in Settings. The installer is downloaded from GitHub only after you tap Update. These requests carry no account, device identifier, or game data; GitHub sees your IP address, the request time, and the app version, and processes them under [GitHub's Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). You can turn off automatic checks in Settings.

舷窗不收集个人数据。应用没有账号、分析统计、广告、跟踪或应用内购买。游戏进度与偏好设置保存在您的设备上。附近联机会通过蓝牙或本地 Wi-Fi，在您连接的设备之间传输对局所需的数据；这些数据不会发送到开发者服务器。删除应用即可删除本机保存的数据。Apple 可能依据其[隐私政策](https://www.apple.com/legal/privacy/)独立处理 App Store 购买信息。Android 版从 GitHub 下载，并会检查更新：开启「自动检查更新」（默认开启）且已联网时，最多每 24 小时向 GitHub 查询一次新版本；也可在设置里手动检查。点「立即更新」后才会从 GitHub 下载安装包。这些请求不包含账号、设备标识或游戏数据，GitHub 会看到你的 IP 地址、请求时间和应用版本号，并依照其[隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)处理。自动检查可在设置中关闭。

For privacy questions, [open a support issue](https://github.com/gxlself/window-seat-support/issues/new) without posting private information; the developer will arrange a private follow-up if needed.

如有隐私问题，请[提交支持问题](https://github.com/gxlself/window-seat-support/issues/new)，不要公开填写私人信息；如需进一步沟通，开发者会安排私下联系。
