Support / 帮助与支持

旅途中有问题？
我们在这里。

联系我们

游戏问题、建议和无障碍反馈，请发送邮件至 gxlself@gmail.com，或在 GitHub 提交问题。请不要在公开问题里发布私人信息。

附近联机怎么开始？

在每台设备上开启蓝牙和 Wi-Fi，进入支持“附近联机”的游戏，由一位玩家建房，其余玩家加入。不需要互联网或账号。乘机时请遵守机组关于无线连接的要求。

进度保存在哪里？

游戏进度与偏好设置保存在本机。部分游戏支持自动存档；卸载应用可能会清除本机数据。

需要网络吗？

单人游戏可离线游玩。附近联机使用设备间的本地连接，也无需互联网。

English

For support, suggestions, or accessibility feedback, email gxlself@gmail.com or open a GitHub issue. For nearby multiplayer, enable Bluetooth and Wi-Fi on each device, then start or join a room in a game that offers Nearby. No internet connection or account is required. Follow crew instructions regarding wireless use on aircraft.
